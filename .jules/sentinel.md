## 2026-10-27 - Fix Command Injection in OS native dialogs
**Vulnerability:** Command injection vulnerability in `try_native_desktop_dialog` via `std::process::Command::new` when interpolating untrusted input (e.g. `title` and `prompt`) directly into OS-specific shell scripts (PowerShell, AppleScript) using `format!`.
**Learning:** This existed because the codebase was generating shell scripts dynamically and embedding user input rather than treating it as arguments or passing via the environment. Escaping is insufficient to prevent sophisticated command injection attacks in these kinds of shells.
**Prevention:** When executing OS-specific shell scripts (e.g., PowerShell, AppleScript) via `std::process::Command` in Rust, prevent Command Injection by passing untrusted user strings via environment variables (`.env()`) and accessing them natively in the script (e.g., `[Environment]::GetEnvironmentVariable()` or `system attribute`), rather than interpolating them directly via `format!`.

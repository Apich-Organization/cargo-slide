## 2026-11-05 - Fixed Command Injection Risk in PIV Prompt
**Vulnerability:** The graphical PIN prompt dialogue interpolated user-provided string arguments (`prompt` and `title`) directly into the script string for PowerShell (`target_os="windows"`) and AppleScript (`target_os="macos"`) before executing it via `std::process::Command`. This allowed arbitrary shell command injection through the `prompt` or `title` variables if they contained specially crafted strings.
**Learning:** Even graphical UI dialog scripts like AppleScript (`osascript`) and PowerShell scripts are vulnerable to command injection if variables are interpolated rather than passed safely through the environment or parameter arrays. Using `.env()` and accessing `$env:VAR_NAME` (PowerShell) or `system attribute` (AppleScript) prevents string interpolation issues.
**Prevention:** Avoid string interpolation of untrusted variables directly into script executions in Rust. Use environment variables mapped via `.env("VAR_NAME", value)` when executing shell-like processes to keep variables separated from the script text.

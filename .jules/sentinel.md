## 2025-05-24 - Command Injection in OS-Specific Native Scripts via std::process::Command
**Vulnerability:** Found command injection in `try_native_desktop_dialog` (`crates/slide-core/src/security/piv.rs`) where `title` and `prompt` strings were directly interpolated into PowerShell (`powershell`) and AppleScript (`osascript`) code using `format!`. String escaping like `.replace('\'', "''")` is brittle and susceptible to breakout.
**Learning:** Even simple GUI dialog popup scripts invoked via system commands are vulnerable if they include user-provided data directly embedded in the script source string.
**Prevention:** When executing OS-specific shell scripts (e.g., PowerShell, AppleScript) via `std::process::Command`, prevent Command Injection by passing untrusted user strings via environment variables (`.env()`) and accessing them natively in the script (e.g., `[Environment]::GetEnvironmentVariable()` or `(system attribute "VAR")`), rather than interpolating them directly via `format!`.

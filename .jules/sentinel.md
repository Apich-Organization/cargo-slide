## 2025-02-14 - Fix Absolute Path Traversal via `Path::join` Root Overwrite
**Vulnerability:** A directory traversal vulnerability existed in the `cargo-slide serve` local web server (`crates/cargo-slide/src/commands/serve.rs`). If a requested URL began with a Windows drive letter or absolute path prefix (e.g. `GET /C:/Windows/System32/win.ini` or `GET /\Windows`), the `.trim_start_matches('/')` would strip only the initial forward slash, leaving `C:/Windows/System32/win.ini`. When `root_dir.join(relative_path)` was called, the absolute path would completely overwrite `root_dir`. This bypassed the existing `ParentDir` (`..`) checks because absolute paths do not necessarily contain parent directories, resulting in arbitrary file read on Windows.
**Learning:** In Rust, `Path::join` exhibits dangerous behavior when joining an absolute path to a base directory—it entirely overwrites the base directory rather than appending to it. While Linux interprets `C:/` as a relative file, Windows recognizes it as an absolute path.
**Prevention:** Before joining user-provided paths with a root directory for file serving, always check if the path contains a root or is absolute (e.g. `Path::new(path).has_root() || Path::new(path).is_absolute()`) and reject it if so.

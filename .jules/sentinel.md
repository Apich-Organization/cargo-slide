## 2023-10-20 - [Command Injection via Native Dialog OS Prompts]
**Vulnerability:** The graphical PIN prompt fallback dialogs for YubiKey PIV authentication used `format!` to interpolate user-provided parameters (`title` and `subtitle`/`prompt`) directly into system shell strings (PowerShell and AppleScript) for native `Command::new` execution. This created a high-risk command injection vulnerability if a malicious presentation package contained crafted text.
**Learning:** Even internal helper strings (like dialog prompts) that pass through OS shell interpreters (such as `osascript` or `powershell -Command`) can act as command injection vectors if any part of the string originates from or is influenced by untrusted external data (like presentation metadata).
**Prevention:** Always escape language-specific metacharacters (e.g., `'` for PowerShell, `"` and `\` for AppleScript) or use APIs that accept separate arguments instead of executing a concatenated script string.

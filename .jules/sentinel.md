## 2024-05-15 - Command Injection in OS Shell Scripts via String Interpolation
**Vulnerability:** Command injection vulnerability in `try_native_desktop_dialog` in `crates/slide-core/src/security/piv.rs` due to the use of `format!` for string interpolation to insert `title` and `prompt` strings directly into `powershell` and `osascript` scripts.
**Learning:** Using standard `replace` methods (like escaping quotes or slashes) in native scripts passed to system shells is not sufficient and prone to bypasses leading to arbitrary command execution when using `std::process::Command`. The `prompt` and `title` variables were being executed as part of the script content directly.
**Prevention:** Pass untrusted data via environment variables (`Command::new(...).env("VAR_NAME", data)`) instead of string interpolation (`format!`). Then, access the environment variables within the script native syntax (e.g., `$env:VAR_NAME` in PowerShell or `system attribute "VAR_NAME"` in AppleScript).

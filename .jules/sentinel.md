## 2024-05-18 - Fixed Command Injection Risk in Native Dialog Prompts
**Vulnerability:** Command injection risk when launching native PIN prompts for YubiKey authentication via shell scripts (osascript, powershell). User input (title, prompt) was interpolated directly into script strings using `format!`.
**Learning:** Even if input comes from seemingly safe internal sources (like title or prompt parameters), directly formatting it into strings passed to a shell creates injection vulnerabilities if those inputs ever become user-controlled. The `replace` mechanism (e.g. escaping quotes) is often insufficient against determined injection attempts or changing shell parser behavior.
**Prevention:** Always pass untrusted or variable input to OS-specific shell scripts (like PowerShell or AppleScript) using environment variables (`.env()`) configured on the `Command` builder, and access those environment variables natively within the script (e.g., `$env:VAR_NAME` or `system attribute "VAR_NAME"`). Do not use string interpolation or formatting to build scripts executing in shells.

## 2024-03-21 - Improving Accessibility for UI Elements with Decorative Emojis and Dynamic State Text
**Learning:** When improving accessibility for UI elements containing decorative emojis and dynamic state text in Leptos, do not use static `aria-label`s as they overwrite the text state for screen readers. Instead, use a dynamic `aria-label` (e.g., `aria-label=move || format!(...)`) to accurately include the changing state, and wrap emojis in `<span aria-hidden="true">` to prevent literal and cluttered screen reader readouts. For elements that toggle text (like a copy button changing from "Copy" to "Copied!"), ensure the ARIA label correctly reflects this state using a reactive closure.
**Action:** When adding ARIA labels to components with mixed icons and reactive text, explicitly separate the visual presentation (using `aria-hidden` on icons/emojis) from the screen reader announcement (using dynamic closures on the `aria-label` attribute on the container).

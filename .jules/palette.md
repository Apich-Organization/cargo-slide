## 2026-11-05 - Wrap emojis with aria-hidden in icon-only buttons\n**Learning:** Emojis inside buttons create a cluttered and literal readout for screen readers if not hidden properly. When relying on emojis for icons without a text equivalent, static aria-labels do help, but screen readers might still read the emoji out loud.\n**Action:** Wrap emojis inside UI elements in <span aria-hidden="true">...</span> to prevent redundant/literal readouts, keeping the screen reader experience cleaner.

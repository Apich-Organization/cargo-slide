## 2024-05-18 - Avoid cloning whole structures in signals\n**Learning:** In Leptos, calling `.get()` on signals that hold large structures (like `SlideDeck` or `Slide`) inside reactive contexts will clone the entire structure, which is bad for performance. Also, deriving signals that require expensive derivation is bad, we should use `Memo::new` instead.\n**Action:** Use `.with(|d| ...)` to read inner fields by reference instead of using `.get()` which clones everything. For option types, `.with(|opt| opt.as_ref().map(|inner| ...))` should be used. For derived state, use `Memo::new(move |_| { ... })`.
